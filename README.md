# PRIMESUN Website — Unified Dark Edition

All pages belong to one website and one domain. Every page now has a shared top navigation linking Home, About & People, COLIZON, FreshSoul, Business and Contact.

## Main pages
- `index.html` — homepage, animated four-face brand cube, About, brands, business figures, future interests, distribution and contact.
- `about.html` — PRIMESUN story, founder, investors and creative/product contributions.
- `brands/colizon.html` — COLIZON brand profile.
- `brands/freshsoul.html` — FreshSoul brand profile.
- `privacy.html`, `disclaimer.html` — initial website information pages.
- `admin.html` — local browser-only figures editor, linked by the small ••• Management Access shortcut in every page footer; not a shared admin dashboard.

## GitHub Pages
Upload the CONTENTS of this folder into the root of one GitHub repository. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`. The same GitHub Pages URL will serve every page.

## Before publishing
Update the placeholder sitemap URLs in `sitemap.xml` after the final GitHub Pages URL or custom domain is known. Add the canonical URL and social preview image metadata after domain setup. Submit the real sitemap in Google Search Console.

## Important operational note
GitHub Pages is static hosting. The admin page stores figures only in local browser storage. It cannot update the live site for all visitors. For that, add a secure authenticated backend/database later.

## Accuracy
PRIMESUN is described as a business identity operated by Nawazish Turk, not as an incorporated company. Future sectors are clearly labelled as future interests. Public pages omit residential address and private document information.
